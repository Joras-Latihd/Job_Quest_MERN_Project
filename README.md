# 💼 Job Quest

**Job Quest** is a full-stack **MERN** job portal that connects **job seekers** and **job providers** in one platform.

Users will be able to **create accounts, search for jobs, post job opportunities, apply for jobs, and more.**

### 🛠️ Tech Stack

**MongoDB • Express.js • React.js • Node.js**
